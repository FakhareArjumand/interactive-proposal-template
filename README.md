# ⚡ Interactive Client Proposal Template

> A dynamic, Apple-inspired HTML/CSS/JS proposal template designed to close high-ticket software deals. Built by **Arjumand Labs**.

### 🧠 The Psychology (Why this works)
The biggest reason software agencies lose high-paying clients is **Sticker Shock**. 

When you send a static PDF proposal for $5,000 to a client with a $4,000 budget, they get overwhelmed and ghost you. This interactive template shifts the client's mindset from *"Should I hire them? (Yes/No)"* to *"Which of these features do I want?"* 

By allowing the client to toggle optional modules and watch the price adjust in real-time, they feel in control of the scope. They can self-adjust the project to fit their exact budget without you having to negotiate blindly. Handing them a premium web experience just to pitch them also proves your frontend engineering skills before you even write a line of production code.

### 🛑 The Problem with PDFs
Static PDF proposals force clients into a binary decision. If the total price is too high, they reject the entire project instead of asking to cut features.

### 💡 The Solution
Send a live web link. Clients act as active participants in the scoping process, exporting a final PDF only when they are happy with the exact feature set and price.

### ⚙️ Features
- **Zero Build Tools:** It's just Vanilla HTML, CSS, and JS in a single file. No NPM, no Webpack, no dependencies. 
- **Live Price Calculator:** JavaScript dynamically recalculates the total investment as clients check/uncheck project modules.
- **Apple-Inspired UI:** Built with an iOS Dark Mode aesthetic (native typography, squircles, glassmorphism, and fluid animations).
- **Print-to-PDF Optimized:** Includes custom `@media print` CSS. When the client clicks "Export as PDF," it automatically strips out the buttons, inverts the dark mode to ink-saving white, and formats the page for standard A4 paper.

### 🛠️ Quickstart
1. Clone the repository.
2. Open `index.html` in any web browser.
3. Edit the hardcoded module data and prices directly in the HTML to fit your agency's services.
4. Host it for free on GitHub Pages and send the live URL to your client.
