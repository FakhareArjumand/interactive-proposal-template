# ⚡ Interactive Client Proposal Template

> A dynamic, single-file HTML/CSS/JS proposal template designed to close high-ticket software deals. Built by **Arjumand Labs**.

### 🛑 The Problem with PDFs
Static PDF proposals force clients into a binary "yes or no" decision. If the total price is too high, they reject the entire project. 

### 💡 The Solution
This interactive web-based proposal allows clients to act as active participants in the scoping process. By toggling optional modules on and off, they can self-adjust the project scope to fit their exact budget in real-time. 

### ⚙️ Features
- **Zero Build Tools:** It's just Vanilla HTML, CSS, and JS in a single file. No NPM, no Webpack, no dependencies. Just host it on GitHub Pages or open it locally.
- **Live Price Calculator:** JavaScript dynamically recalculates the total investment as clients check/uncheck project modules.
- **Print-to-PDF Optimized:** Includes custom `@media print` CSS. When the client clicks "Export as PDF," it automatically strips out the buttons, inverts the dark mode to ink-saving white, and formats the page for standard A4 paper.
- **Deep Dark UI:** Designed with modern software agency aesthetics (`#060E20` color palette).

### 🛠️ Quickstart
1. Clone the repository.
2. Open `index.html` in any web browser.
3. Edit the hardcoded module data and prices directly in the HTML to fit your agency's services.
